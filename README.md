# Todo Application

A distraction-free, local task management tool written in vanilla JavaScript with persistent browser storage.

## Features

- **Task Lifecycle:** Add, complete, filter (Active/Completed/All), and remove tasks.
- **Persistence:** LocalStorage integration to retain tasks across browser sessions.
- **Keyboard Navigation:** Enter-to-submit and inline task editing.

## Tech Stack

- Vanilla JavaScript (DOM Events)
- HTML5
- CSS3

## Run

Open `index.html` directly in your browser.
